Is more RAM always better?


No. Giving a server far more RAM than it needs can cause longer garbage-collection pauses. Use about what the calculator recommends, and look at CPU speed if you still get lag.


Why does my server lag even with enough RAM?


Minecraft runs its main game loop on one CPU thread, so single-core CPU speed matters a lot. Lowering view distance, pre-generating your world (with Chunky) and adding performance mods often help more than extra RAM.


How much RAM do I need if I host on my own PC?


Leave at least 2–4 GB free for your operating system and the game client. For example, if the calculator says 8 GB and you also play on that same PC, 16 GB of total system RAM is more comfortable.


Should -Xms and -Xmx be the same?


Yes. For a dedicated server, set both to the same value (Aikar's flags do this) so the JVM doesn't waste time resizing the heap.


How many mods can 8 GB handle?


Usually about 150–250 mods for a small group of friends, depending on the mods. Tech and worldgen mods use more memory than small utility mods.
